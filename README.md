# xhyumiracle.com

Personal homepage (v9: sky by type, the anime sky). Static, zero-dependency: one HTML file, one stylesheet,
two scripts, six self-hosted font files (CJK subset is 5KB), one avatar, one CV PDF.

Serve the `/` of this directory with any static file server.
`?shot=<section-id>` freezes a section fullscreen for screenshots.
